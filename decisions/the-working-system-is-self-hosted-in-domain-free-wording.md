# The working system is self-hosted in domain-free wording

Tags: working-system

## Rationale

The system describes itself: its rules are decisions of the root node, written without trading, venue or market vocabulary wherever the rule is about the system itself; a rule whose subject is a named subtree of modules names that subtree and travels with it at extraction. The whole system — the anatomy, the home rule, the facts/decisions split, the spec lifecycle — can later be lifted into a repository of its own by moving a handful of root decisions together with AGENTS.md and the project-method skill. Venue examples in those files are illustrations, not dependencies.

## Rejected alternatives

- Describing the system only in AGENTS.md: a constitution in context must stay short; the claims it settles deserve the claim process like any other judgement.
- Weaving domain terms into the rules: every mention of a venue or a codec would have to be undone at extraction time.
