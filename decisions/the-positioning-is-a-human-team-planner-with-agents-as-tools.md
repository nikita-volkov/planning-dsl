# The positioning is a human-team planner with agents as tools

Tags: positioning

## Rationale

The product is positioned as a planner for human teams: an open plan format, authored and refined through LLM grilling sessions, executed by tools. AI agents appear as executors and as authoring assistants — tools amplifying people — never as autonomous project managers. The wedge use case is grilling session → `plan.yaml` → tracker export; agent orchestration is a secondary consumer of the same format (our own dogfood), explicitly not the marketing position. Height's shutdown (September 2025) is the cautionary tale for black-box autonomous-PM positioning; the open format is the opposite bet.

## Rejected alternatives

- Agent-orchestration positioning (the format as an agent-orchestration DSL first): a crowded 2026 category with strong incumbents, and it abandons the unoccupied niche — planning as code for mixed human/agent teams has no canonical standard yet.
- Neutral no-positioning (just a format spec): formats without a product that forces them through real plans die as good ideas; the wedge product is what hardens the schema.
