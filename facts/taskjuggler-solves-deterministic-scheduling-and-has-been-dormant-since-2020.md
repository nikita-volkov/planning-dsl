# TaskJuggler solves deterministic scheduling and has been dormant since around 2020

Tags: competition, scheduling

## Rationale

TaskJuggler's scheduling core — deterministic allocation of task DAGs onto executors with availability, concurrency and project deadlines — is fully solved, with semantics mature enough to adopt as this project's reference model for the scheduler layer. The project has seen no release since around 2020 and appears dormant, so it is a semantics donor, not a competitor: its interface (a compiler-grade project file with its own syntax) never crossed over to YAML, LLM authoring, or tracker sync.

## Evidence

- Web research session of 2026-11-02; taskjuggler.org release history showed no release since ~2020 (checked again 2026-11-03 via the handoff record).
