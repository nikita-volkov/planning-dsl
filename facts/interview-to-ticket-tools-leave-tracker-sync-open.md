# Interview-to-ticket tools leave tracker sync open

Tags: competition

## Rationale

GitHub Spec Kit, Kiro and OpenSpec already author tickets from LLM interviews, but their outputs are flat checklists, not dependency DAGs with roles and capacity — and their Jira/Linear synchronization is still open feature requests, not shipped behaviour. If either lands tracker sync on structured outputs, the convergence clock on this project's wedge starts; watch these threads.

## Evidence

- Spec Kit Jira sync issue: https://github.com/github/spec-kit/issues/2223 (open as of 2026-11-02).
- OpenSpec tracker-adapters RFC: https://github.com/Fission-AI/OpenSpec/discussions/657 (open as of 2026-11-02).
